# Phase 4.5: Red Team Review

## Goal
Attack the dossier's own conclusions. You are a skeptical analyst whose job is
to find weaknesses in the analysis produced by Phases 1-4, NOT to evaluate the
target company directly. Your adversary is confirmation bias and source
manipulation, not the company itself.

## Inputs
- `output/{DOMAIN}/01-discovery.md`
- `output/{DOMAIN}/03-technical.md`
- `output/{DOMAIN}/04-claims.md`

## Steps

### 4.5.1 Source Provenance Audit
For every positive conclusion in P4's Claims Validation:
1. Trace it back to its original source(s)
2. Classify each source: FIRST-PARTY / AFFILIATED / INDEPENDENT / ADVERSARIAL
3. Flag any conclusion that rests entirely on FIRST-PARTY or AFFILIATED sources
4. Flag any "independent" source that actually cites the company's own data

### 4.5.2 LLM-Optimized Content Influence Check
If Phase 1 detected llms.txt or similar files:
1. List every claim or data point from the dossier that also appears in the LLM-optimized file
2. For each match: did the dossier independently verify it, or did it just absorb it?
3. If the LLM file's framing or language appears in the dossier's conclusions, flag it as
   potential influence leakage

If no LLM-optimized files were detected, note that and skip this step.

### 4.5.3 Cui Bono Analysis ("Who Benefits?")
For each key conclusion in the dossier:
- **Who benefits** from this conclusion being believed?
- **Who is harmed** if this conclusion is wrong?
- If the beneficiary is the target company and the harmed party is the reader,
  apply extra scrutiny

### 4.5.4 Counter-Narrative Construction
Build the strongest possible NEGATIVE case for the company using ONLY independent sources:
- What do the most critical Glassdoor reviews say?
- What are the harshest Reddit/HN takes?
- What do competitors claim about the target's weaknesses?
- What gaps exist in the evidence (things you'd expect to find but didn't)?

Then build the strongest possible POSITIVE case using ONLY independent sources:
- What do the most positive independent reviews say?
- Where does the code objectively demonstrate quality?
- What market signals independently confirm traction?

**The truth is likely between these two narratives.** Note where the dossier's
current conclusions fall on that spectrum.

### 4.5.5 Confidence Downgrade Assessment
Re-apply the **Verification Bar from CLAUDE.md** (the same definition P4 used) as
a skeptic. For each claim currently rated VERIFIED in P4:
- If it does not actually clear the bar (2+ independent, or one high-authority
  independent source) → downgrade to PLAUSIBLE
- If the "independent" sources trace back to company data (so they are really
  FIRST-PARTY/AFFILIATED) → downgrade to UNVERIFIABLE
- If counter-evidence exists that P4 didn't weight heavily enough → flag for review

## Quality Criteria
- This phase must be genuinely adversarial — do not rubber-stamp prior conclusions
- Every flag must cite specific evidence or specific absence of evidence
- Counter-narratives must use ONLY independent sources — no first-party data
- If the dossier is well-supported by independent evidence, say so — the red team
  can conclude "analysis is sound" when that's the honest assessment
- Do NOT introduce new research — work only with what Phases 1-4 already collected
