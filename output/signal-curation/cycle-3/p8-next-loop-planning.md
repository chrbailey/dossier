**Projection for Cycle 4:**
- If we use the same question-driven approach: likely 20-30 new items (new questions generate new sources)

**Assessment: The convergence threshold of < 3 new items is inappropriate for current events research.** The subjects of this dossier are producing real-world developments (lawsuits, legislation, product launches, technical results) faster than the research loop can exhaust them. The threshold was designed for a finite evidence space, but this topic has a continuously expanding frontier.

Rather than waiting for < 3 new items (which may never happen during an active news cycle), consider:

1. **Novelty convergence:** Mean novelty < 0.35 for 2 consecutive cycles (we're at 0.55)

## 4. Recommendations

### 4.1 Primary Question: Should We Continue to Cycle 4?

**Recommendation: CONVERGE EARLY with targeted refinement.**

Rationale:

1. **The core signal structure is established.** Three cycles have identified and validated the major patterns: military AI governance crisis, consciousness/interpretability research, world models convergence, enterprise risk, and agentic infrastructure. A fourth cycle is unlikely to discover a new major pattern.

2. **Evidence count isn't converging, but novelty is declining.** The 37 items in Cycle 3 were mostly coverage and corroboration, not breakthroughs. The genuinely novel findings (system card, SAE deception study, legislative text) could have been captured as a targeted supplement, not a full cycle.

3. **Open questions are event-dependent.** NQ1 (court ruling), NQ2 (NDAA enforcement), NQ4 (Pentagon capabilities) depend on future events, not on further research. No amount of searching will answer them.

4. **Infrastructure debt matters more than volume.** The corroboration system is broken -- verified tier will remain empty forever with current implementation. Fixing this would increase the value of existing evidence more than adding another cycle of raw collection.

5. **This is the checkpoint cycle.** The contract specifies checkpointInterval: 3. Three cycles is a natural stopping point for assessment.

### 4.2 What Cycle 4 Could Investigate (If Continued)

If the decision is to continue, the only high-value targets are:

1. **Consciousness replication on Anthropic models specifically** -- the deception-feature study (ID 104) used a different model. Running it on Claude would be the decisive test.
2. **NDAA enforcement in April 2026** -- the first governance team deadlines. This is a calendar event, not a search target.
3. **Murati signal** -- three cycles of nothing. Either stop tracking or add her as a dedicated source with platform-specific search.
4. **Chinese AI developments** -- Qwen/DeepSeek are in the contract's source list but unqueried. This is the largest genuine gap in coverage.

Of these, only #4 (Chinese AI) represents a genuinely untapped evidence space. The others are either event-dependent or model-access-dependent.

### 4.3 Infrastructure Fix: Corroboration Counting

**This should be fixed before ANY further cycles.** Current state:

- The evidence store's `insert()` only increments corroboration on exact content hash duplicates
- Cross-evidence corroboration (same topic from different sources) is never counted
- Result: 145 working items, 0 verified items, verified tier structurally unreachable
- The entire tier promotion system is broken at the verified level

**Minimum fix:** Implement a `compute_corroboration()` method that:
1. Groups evidence by topic/cluster (using existing signal dimensions)
2. Counts cross-source evidence on the same topic as corroboration
3. Runs as a batch operation after each cycle's P4 signal extraction

**Estimated effort:** Medium. Requires defining "same topic" operationally (could use composite score similarity + source diversity), adding a batch method, and running it on the existing 148 items.

### 4.4 Recommended Path

**Option A: Fix infrastructure, then converge (RECOMMENDED)**
1. Fix corroboration counting
2. Run corroboration on all 148 evidence items
3. Promote qualifying items to verified tier
4. Write final synthesis incorporating tier structure
